# CISSP - Domain 2: Asset Security

## Data Roles
### Data Owner/Controller
- Decides access
- Defines security requirements based on sensitivity

### Data Custodian
- Implements security controls
- Enforce protection across data lifecycle

### Data Steward
- Ensures consistency across data records
- Protects value of data in absence of data owner
- Determines way personal data is processed

### Data Controller
- Decides purposes and methods of data processing

### Data Protection Officer (DPO)
- Mandatory to have when handling health related data cross jurisdictions (GDPR)

## Data Lifecycle
1. Create
    1. Classify content - Data owner
2. Store
    1. Encryption, baseline controls, access controls, logging - Data Custodian
3. Use
    1. DLP
    2. Digital Rights Management (DRM)
4. Share
5. Archive
6. Destroy

## IT Asset Management Lifecycle
1. Planning (or discovered)
    1. Identify asset and align to org controls
    2. Classify
2. Acquisition
    1. Developed in house
    2. COTS
    3. Deploy securely
3. Management
    1. Monitoring
    2. Adapting to changes
    3. Backups/data archival
    4. Training users
4. Retirement
    1. Data destruction

## Data Categorization
- NIST SP 800-60r1
- FIPS 199
- GDPR

## Data Destruction
- Clearing
    - Overwriting storage media with random values
- Purging
    - Degausing magnetic field
        - Makes drive unusable
- Physical destruction
    - Shredding
    - Chemically etching
    - Incinerating hardware
- Crypto-erase (crypto-shredding)
    - Cloud environments
